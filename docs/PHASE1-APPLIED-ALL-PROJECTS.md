### 2️⃣ 环境变量管理

**新增文件**: `.env.example`

```bash
# 环境配置示例
NODE_ENV=development
PORT=8000

# API 配置（如果有）
# API_KEY=your_api_key_here

# 功能开关
DEBUG=false
LOG_LEVEL=info
```

**使用方法**:
```bash
# 1. 复制示例文件
cp .env.example .env

# 2. 填入实际配置值
# 3. .env 已被 .gitignore 保护，不会提交
```

### 3️⃣ 默认配置文件

**新增文件**: `config/default.json`

```json
{

    "version": "1.0.0",
    "description": "项目配置"
  },
  "env": "development",
  "features": {}
}
```
