# 🤝 AI与人类协作沟通协议

## 目标：提高效率、减少误解、快速解决问题

---

## 📝 用户报告问题时应该提供的信息

### 最小信息集（必须提供）
```
✅ 发生了什么（一句话描述）
✅ 预期发生什么
✅ 实际发生了什么
✅ 控制台的错误信息（如果有）
```

### 完整信息集（推荐提供）
```
✅ 最小信息集的所有内容
✅ 复现步骤（1-2-3）
✅ 浏览器和版本
✅ 相关截图/控制台日志复制
✅ 最近的改动（"我刚才改了XXX"）
```

### 示例对比

❌ **不好的报告**：
```
用户："没有声音"
```
→ 信息不足，需要来回追问

✅ **好的报告**：
```
用户："点击播放按钮后，没有声音。控制台显示：
[DOMContentLoaded] ✅ 已加载 25 个可朗读段落
[playParagraph] ⚠️ 超时：3秒内未开始播放

浏览器：Chrome 121
系统：macOS Sonoma 14.2"
```
→ 信息完整，可以立即开始诊断

## 🤖 AI回复时的标准

### 第1步：确认收到（不要急着修复）
```
✅ 收到，我看到问题是：[复述问题]
✅ 我需要确认：[列出需要的信息]
```

### 第2步：诊断（不要猜测）
```
✅ 从错误信息看，可能是：[分析]
✅ 让我先检查相关代码...
✅ 添加日志来确认问题位置...
```

### 第3步：修复（不要遗漏）
```
✅ 找到问题了：[根本原因]
✅ 修复方案：[具体改动]
✅ 我会检查是否还有其他地方有同样的问题...
```

### 第4步：验证（不要假设）
```
✅ 已修复，建议测试步骤：
1. 刷新页面
2. 点击播放
3. 应该听到声音

如果还有问题，请告诉我控制台的完整日志。
```

## 🔄 典型对话流程

### 场景1：明确的问题
```
用户："TTS无法播放，控制台显示xxx错误"
AI："收到，我看到错误是xxx。让我检查相关代码..."
AI："找到问题了，是xxx导致的。正在修复..."
AI："已修复，请刷新页面测试。"
```

### 场景2：不明确的问题
```
用户："有问题"
AI："我需要更多信息来帮你。请告诉我：
1. 具体是什么问题？
2. 控制台显示什么？
3. 如何复现？"
```

### 场景3：复杂的Bug
```
用户："修复后还有其他地方报错"
AI："让我全局搜索一下，确保修复所有相关问题..."
AI："发现还有X处同样的问题，我会一次性全部修复。"
```

## 📊 沟通质量评分

### 好的沟通（目标）
- ✅ 问题1次描述清楚
- ✅ 修复后问题解决
- ✅ 总耗时 < 5分钟

### 需要改进的沟通
- ⚠️ 需要来回追问3次以上
- ⚠️ 修复后出现新问题
- ⚠️ 总耗时 > 30分钟

### 糟糕的沟通（避免）
- ❌ 信息严重不足
- ❌ 反复修复同一类问题
- ❌ 总耗时 > 1小时

## 🎯 双方责任

### 用户的责任
1. **提供完整信息**：使用Bug报告模板
2. **描述具体问题**：不要说"有问题"、"不行"
3. **运行诊断命令**：如果AI要求
4. **反馈结果**：修复后测试并报告

### AI的责任
1. **不要猜测**：基于事实分析
2. **全局修复**：不要遗漏相关问题
3. **提供背景**：说明为什么会有这个问题
4. **给出建议**：如何避免类似问题

---

## 💡 提高沟通质量的技巧

### 用户方
1. **截图比打字快**：直接截图控制台
2. **复制日志**：不要手打，直接复制
3. **说环境**：浏览器、系统、版本
4. **说步骤**：1-2-3怎么操作的

### AI方
1. **先复述**：确保理解正确
2. **给证据**：展示日志/代码片段
3. **说计划**：先诊断，再修复
4. **防遗漏**：全局搜索相关问题

## 📝 紧急情况的处理

### 如果问题影响使用
```
用户："这个很紧急，我需要立即使用！"
AI："收到，优先处理。让我先快速恢复功能，
再彻底修复。预计需要X分钟。"
```

### 如果问题无法复现
```
用户："刚才有问题，现在好了"
AI："先记录下来，可能是个间歇性Bug。
我会添加更多日志，下次出现时能捕获信息。"
```

3. **改进流程**：如何更快地发现类似问题？
4. **分享经验**：告诉对方学到了什么

## 📞 快速联系方式

### 紧急程度分级
- 🔴 **紧急**：完全无法使用 → 立即处理
- 🟡 **中等**：部分功能受影响 → 尽快处理
- 🟢 **轻微**：小问题/建议 → 有时间处理

### 响应时间承诺
- 🔴 紧急：立即诊断，5分钟内给出方案
- 🟡 中等：10分钟内开始处理
- 🟢 轻微：30分钟内开始处理
