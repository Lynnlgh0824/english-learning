## 🔗 在浏览器中打开

### 方法1：直接双击
找到 `PROJECT-SUMMARY.html` 文件，双击即可在浏览器中打开

### 方法2：拖拽
将 `PROJECT-SUMMARY.html` 拖拽到浏览器窗口中

### 方法3：右键打开
右键文件 → 打开方式 → 选择浏览器（Chrome/Safari）

## 📌 创建桌面快捷方式

### macOS
1. 右键点击 `PROJECT-SUMMARY.html`
2. 选择「制作替身」
3. 将生成的替身拖到桌面

### Windows
1. 右键点击 `PROJECT-SUMMARY.html`
2. 选择「发送到」→「桌面快捷方式」

### 或者：在浏览器中创建书签
1. 在浏览器中打开文档
2. 按 `Cmd+D` (Mac) 或 `Ctrl+D` (Windows)
3. 添加到书签栏
4. 设置名称：「项目经验总结」
