# English Learning TTS - 产品文档

> Version: 1.0 | Last Updated: 2026-06-01

---

## 1. 产品愿景

**核心使命**: 让英语学习更高效、更智能、更个性化。

通过浏览器原生 TTS 技术，将任何英文内容（TED、YouTube、文章）转化为可听、可跟读、可查词的交互式学习材料，零成本、零门槛。

---

## 2. 目标用户画像

### 职场人士 (Working Professional)
- **英语水平**: CET-4/6
- **场景**: 通勤、午休、碎片时间
- **需求**: 提升商务英语听力，高效利用碎片时间
- **痛点**: 没有大块时间系统学习，传统课程太贵

### 准留学生 (Prospective Student)
- **英语水平**: IELTS 5.5-6.5
- **场景**: 备考期间集中训练
- **需求**: 适应全英文环境，精准听力理解
- **痛点**: 听力跟不上语速，词汇量不够

### 英语爱好者 (Enthusiast)
- **英语水平**: 中级
- **场景**: 日常学习、影子跟读
- **需求**: 通过跟读提升口语和听力
- **痛点**: 找不到合适的跟读材料，不知道发音对不对

## 4. 用户旅程

### 核心流程

```
打开 index.html → 选择/创建学习项目 → 进入学习页
    → 选择语速模式 → 点击播放 → 跟读/精听
    → 点击单词查义 → 完成后查看进度
```

### 首次使用

```
打开页面 → 看到空状态引导 → 点击"从 URL 创建"
    → 粘贴 YouTube/TED 链接 → 自动生成学习包
    → 进入学习页 → 选择语速 → 开始学习
```

### 日常复习

```
打开页面 → 看到学习记录列表 → 选择未完成的课程
    → 系统提示"上次学到第 X 段" → 点击"继续学习"
    → 从上次位置继续 → 学习完成
```
