# 📅 按日期分组学习记录功能说明

## 🎯 新功能概述

学习记录现在会按照日期自动分组，方便你：
- 📊 查看每天的学习进度
- 📈 统计每天的学习量
- 🗓️ 快速找到特定日期的学习内容
- 📱 更直观地了解学习习惯

---

## 🎨 两种查看模式

### 模式一：按日期查看（默认）📅

**特点**：
- 同一天的学习记录聚合在一起
- 显示每个日期的统计信息
- 自动显示"今天"、"昨天"
- 按时间倒序排列（最新的在前）

**显示内容**：
```
📅 2025-02-05  星期三
📚 1 篇  📖 20 词  💬 15 表

┌─────────────────────┐
│ 学习卡片 1         │
└─────────────────────┘

📅 2025-02-04  星期二
📚 2 篇  📖 40 词  💬 30 表

┌─────────────────────┐
│ 学习卡片 1         │
├─────────────────────┤
│ 学习卡片 2         │
└─────────────────────┘
```

---

### 模式二：列表查看 📋

**特点**：
- 所有学习记录平铺显示
- 按添加时间倒序
- 适合快速浏览所有记录

**显示内容**：
```
┌─────────┬─────────┬─────────┐
│ 记录 1  │ 记录 2  │ 记录 3  │
├─────────┼─────────┼─────────┤
│ 记录 4  │ 记录 5  │ 记录 6  │
└─────────┴─────────┴─────────┘
```

---

## 🔄 切换查看模式

在查看器顶部，有两个按钮：

```
[📅 按日期查看]  [📋 列表查看]
     ↑ 激活状态        未激活
```

点击按钮即可切换视图。

---

## 📊 日期统计信息

每个日期分组显示：

| 统计项 | 说明 |
|--------|------|
| **📚 X 篇** | 当天的学习记录数量 |
| **📖 X 词** | 当天学习的总词汇数 |
| **💬 X 表达** | 当天学习的总表达数 |

---

## 📅 智能日期显示

系统会自动识别特殊日期：

| 日期 | 显示 |
|------|------|
| 今天 | 显示"今天" |
| 昨天 | 显示"昨天" |
| 更早的日期 | 显示完整日期（YYYY-MM-DD）|

## 💾 自动保存逻辑

### 场景一：第一次学习

**日期**：2025-02-05

**保存结果**：
```json
{
  "records": [
    {
      "id": "2025-02-05-learning-1",
      "date": "2025-02-05",
      ...
    }
  ],
  "byDate": {
    "2025-02-05": {
      "count": 1,
      "totalWords": 20,
      "totalExpressions": 15,
      "records": ["2025-02-05-learning-1"]
    }
  }
}
```

---

### 场景二：同一天多次学习

**日期**：2025-02-05

**第一次学习**：
```json
{
  "2025-02-05": {
    "count": 1,
    "totalWords": 20,
    "records": ["record-1"]
  }
}
```

**第二次学习（同一天）**：
```json
{
  "2025-02-05": {
    "count": 2,              // 更新为 2
    "totalWords": 40,         // 更新为 20 + 20
    "totalExpressions": 30,   // 更新为 15 + 15
    "records": [              // 添加新记录
      "record-1",
      "record-2"
    ]
  }
}
```

## 🆘 常见问题

### Q: 如何看到所有今天的学习记录？
A: 打开查看器，默认就是"按日期查看"，找到"今天"分组即可。

### Q: 可以按周或月查看吗？
A: 目前只支持按日查看，你可以滚动查看多天的记录。

### Q: 如何修改某天的记录？
A: 直接编辑 `~/english-learning/records/` 中对应的文件。

### Q: 同一天的学习记录会合并吗？
A: 不会，每条记录独立保存，但会按日期分组显示。
