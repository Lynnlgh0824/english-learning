## 🎯 每日学习流程

### 第一步：学习新内容

在 Claude Code 中运行：

```bash

```

**示例**：
```bash
/learn-english https://www.ted.com/talks/simon_sinek_how_great_leaders_inspire_action
```

## 📊 理解学习统计

### 顶部统计面板

```
┌─────────────────────────────────┐
│  📚 学习记录    📖 词汇学习    ⏰ 学习小时 │
│      5           100          7.5      │
└─────────────────────────────────┘
```

**说明**：
- **学习记录**：总的学习记录数
- **词汇学习**：累计学习的词汇数量
- **学习小时**：估算的学习总时长（每篇1.5小时）

### 日期分组统计

```

```

**说明**：
- **📚 X 篇**：当天的学习记录数量
- **📖 X 词**：当天学习的总词汇数
- **💬 X 表达**：当天学习的总表达数

## 🆘 常见问题

### Q: 找不到"今天"的记录？
A:
1. 确认今天已经使用 `/learn-english` 学习了内容
2. 刷新浏览器页面（Cmd+R 或 F5）
3. 点击"☀️ 今天"按钮

### Q: 日期导航不显示？
A:
- 确保使用的是"📅 按日期查看"模式
- 至少有一条学习记录
- 刷新浏览器页面

### Q: 如何修改学习记录？
A:
1. 直接编辑 `~/english-learning/records/` 中的文件
2. 或重新运行 `/learn-english` 生成新记录

### Q: 统计数据不准确？
A:
- 刷新浏览器页面
- 数据基于记录数自动计算（每篇20词，1.5小时）
