## 2. 核心模块

### 2.1 TTS 引擎 (tts-common.js, 1133 行)

```
┌─────────────────────────────────────┐
│           TTS Queue Manager          │
│                                      │
│  用户点击播放                         │
│       │                              │
│       ▼                              │
│  ┌─────────────┐                    │
│  │ 解析段落列表  │                    │
│  └──────┬──────┘                    │
│         ▼                            │
│  ┌─────────────┐    ┌────────────┐  │
│  │ 创建         │───▶│ SpeechSynth │  │
│  │ Utterance   │    │ .speak()   │  │
│  │ 队列        │    └─────┬──────┘  │
│  └─────────────┘          │         │
│                     ┌─────▼──────┐  │
│                     │ onboundary  │  │
│                     │ 事件回调    │  │
│                     └─────┬──────┘  │
│                           │         │
│              ┌────────────┼────┐    │
│              ▼            ▼    ▼    │
│          高亮段落     更新进度  自动滚动│
└─────────────────────────────────────┘
```

**关键设计决策**:
- **队列策略**: 在单次用户点击事件中预创建所有 Utterance，绕过浏览器自动播放限制
- **语音选择**: 优先推荐女声（Microsoft Zira, Google UK English Female）
- **降级策略**: 在线 → 云端 TTS 语音 → 离线 → 本地内置语音

### 2.2 学习记录页 (records/*.html)

每个学习记录是一个独立的 HTML 文件，包含：
- 完整英文原文（段落结构）
- 中文翻译
- 词汇卡片（20 词/课）
- 习语卡片（15 个/课）
- 句型分析（8 个/课）
- 练习题
- 内嵌 TTS 控制面板

## 3. 数据流

```
URL 输入 → Claude Code /learn-english → 生成学习包 HTML
                                              │
                                              ▼
                                    records/2026-xx-xx-title.html
                                              │
                                              ▼
                                    更新 data.json 索引
                                              │
                                              ▼
                                    index.html 加载并展示
```

### data.json 结构

```json
{
  "records": [
    {
      "id": "2026-02-06-coming-home",
      "title": "Coming Home",
      "type": "youtube",
      "sourceUrl": "https://youtube.com/...",
      "date": "2026-02-06",
      "wordCount": 450,
      "expressionCount": 15,
      "sentencePatternCount": 8,
      "progress": {
        "completed": [1, 3, 5, 7],
        "lastPosition": 12,
        "totalSentences": 32
      }
    }
  ]
}
```
