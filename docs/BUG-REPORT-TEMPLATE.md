## ✅ 我自己修复Bug时的检查清单

### 第1步：信息收集（不要跳过！）
- [ ] 获取完整的控制台日志（包括所有错误）
- [ ] 获取网络请求截图（如果有API调用）
- [ ] 获取具体的复现步骤
- [ ] 确认浏览器版本和操作系统
- [ ] 尝试在控制台运行最小化复现代码

### 第2步：问题定位
- [ ] 阅读错误信息，不要猜测
- [ ] 使用搜索查找相关代码
- [ ] 添加更多日志来确认问题位置
- [ ] 不要急着修复，先确认根本原因

### 第3步：修复
- [ ] 一次性修复所有相关问题（用全局搜索）
- [ ] 修复后自测（不要立即报告完成）
- [ ] 添加防止回归的检查

### 第4步：验证
- [ ] 在多个浏览器中测试
- [ ] 测试边界情况（空值、null、undefined）
- [ ] 确认没有引入新问题

### 第5步：报告
- [ ] 说明根本原因（是什么导致的）
- [ ] 说明修复方案（怎么修的）
- [ ] 说明如何验证（怎么测试）
