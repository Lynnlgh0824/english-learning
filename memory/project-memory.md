## 📋 项目概述

English Learning 是一个语言学习平台，提供全面的英语教育工具，包括 TTS（文本转语音）功能和交互式学习体验。

### 核心功能
- **TTS 系统**: 文本转语音功能，支持多种语音和语速
- **交互式学习**: 沉浸式学习体验
- **外部集成**: Moltbook 认证系统
- **进度追踪**: 学习进度监控

### 技术栈
- **框架**: Next.js 15 (App Router)
- **运行时**: React 19
- **语言**: TypeScript
- **包管理**: pnpm

---

## 🎯 项目目标

1. 提供高质量的英语学习工具
2. 支持多种学习方式（听力、口语、阅读）
3. 集成第三方服务增强体验
4. 追踪和展示学习进度
