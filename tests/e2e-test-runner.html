💻 命令行运行

也可以在终端中直接运行测试脚本：

# 安装依赖（首次运行） npm install puppeteer # 运行 E2E 测试 node tests/automated-e2e-test.js # 运行特定测试 node tests/automated-e2e-test.js --page=coming-home

📖 使用说明

  • 确保服务器已启动：python server.py 或 ./start-server.sh
  • 首次运行需要安装依赖：npm install puppeteer
  • 测试会自动打开浏览器并执行测试用例
  • 测试结果和截图保存在 test-reports/ 和 test-screenshots/ 目录
  • 无头模式适合 CI/CD 环境，有界面模式适合调试
